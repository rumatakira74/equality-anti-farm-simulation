# Результаты симуляции equality-anti-farm-simulation (воспроизведение)

- Модель: https://github.com/rumatakira74/equality-anti-farm-simulation (`farm_model.py`, Python).
- Прогон: 8 прогонов Монте-Карло на сценарий × 60 месяцев, усреднение по прогонам.
- Патч `farm_model_pure.py`: numpy в песочнице недоступен и pip запрещён, поэтому
  выборка Пуассона заменена точной реализацией на стандартной библиотеке
  (разбиение λ на части по 30 + алгоритм Кнута, отдельный поток
  `random.Random(seed*7919+1)`), `nanmean` — фильтрацией NaN. Результат
  статистически эквивалентен авторскому, но не побитово идентичен (другой
  ГПСЧ-поток).
- Выводы интегрированы в KNOWLEDGE.md v9.2, раздел 7.7.

## Базовый сценарий

K = 3, слоты 3/5/10, посевной круг 100, ферма 20 устройств/мес., потолок фермы,
recruit = 0,1 новичка/чел./мес., vouch_prob = 0,5, $200 за устройство.

- Месяц 12: честные 232, ферма 38 (13,9%), безубыточная цена $0,234.
- Месяц 24: 568 / 334 (36,8%), $0,035.
- Месяц 27: пик доли фермы ≈ 40%.
- Месяц 38: безубыточная цена пересекает $0,01 — ферма окупается при цене единицы $0,01.
- Месяц 60: 8348 / 1140 (12,1%), $0,0053.

## Группы сценариев

1. **Правила поручительств** — `база`, `узко` (2/2/10), `щедро` (5/8/15), K = 2/3/4/5.
2. **Проникновение фермы** — покупка поручительств 0 / 0,5 / 2 / 8 / 20 кошельков/мес.
3. **Посевной круг** — 50 / 100 / 300 / 1000 кошельков.
4. **Бюджет фермы** — 5 / 20 / 50 / 100 устройств/мес.

## Формат CSV

Колонки: `month, honest_active, honest_pending, farm_active, farm_pending, farm_share, farm_cost_usd, farm_units_net, breakeven_price, farm_profit_usd` — средние по 8 прогонам; `farm_profit_usd` — при цене единицы $0,01.
