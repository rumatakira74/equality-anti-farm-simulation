# Симуляция защиты от ферм (Equality Project — платформа сетей доверия)

Агентная модель: рост сети через поручительства и попытка фермы кошельков закрепиться в ней.
**DOI:** [10.5281/zenodo.23474357](https://doi.org/10.5281/zenodo.23474357)

Автор: Лапчинский Кирилл (Kirill Lapchinsky), 13 октября 2026 г. (базовая модель, этап 1.1); 18 октября 2026 г. — расширение этапа 1.2 (демередж, комиссия, окно переводимости, отложенные переводы, мораторий).

## Структура репозитория

- **KNOWLEDGE.md** — устаревший снимок платформенного документа v9.3: содержание удалено, внутри ссылки на актуальную версию (`docs/KNOWLEDGE.md` v9.16 в equality-trust-networks).
- **farm-attack-economics.md** / **farm-attack-economics-ENG.md** — устаревшие копии записки об экономике фермерской атаки: ссылки на актуальные версии в equality-trust-networks.

## Запуск на вашем ноутбуке

```
mkdir -p ~/sim && cd ~/sim
# положите сюда Mistral/farm_model.py и Mistral/requirements.txt
uv venv && source .venv/bin/activate
uv pip install -r requirements.txt
python farm_model.py --regression   # сверка с каноническими цифрами базы 1.1
python farm_model.py --stage12      # механизмы этапа 1.2: демередж, комиссия, окно, P
python farm_model.py --stage12 --group ПОДСТРОКА  # группировка (фильтр сценариев stage12; без режима группы --group игнорируется)
python farm_model.py --a9           # тема A9: канон $120 и сетка чувствительности
```

Параметры сценариев — в классе `Params` в начале файла. Чтобы проверить своё значение, добавьте строку в словарь сценариев внутри `main()`, например:
`"K=3, слоты 4/6/10": replace(base, slots_young=4, slots_old=6)`.
Один прогон с 8 повторами занимает меньше минуты.

## Что внутри модели

- Честные люди приходят по цепочке знакомств: каждый просит нескольких активных поручителей, согласие с вероятностью `vouch_prob`.
- Поручитель должен быть активным, не младше 3 месяцев и иметь свободный слот. Слот освобождается после 3 периодов выпуска поручаемого либо через 3 месяца, если тот не стал активным.
- Ферма регистрирует кошельки (платит за устройства), немного проникает к честным поручителям (`infiltrate_per_month`) и растёт кольцом взаимных поручительств.
- Каждый активный кошелёк выпускает 1000 единиц в месяц. Для фермы считаются стоимость (устройство + электричество) и доход; из выпуска первого года 10% уходит поручителям, и для кошельков, за которых поручились честные люди, это потеря фермы.
- Этап 1.2 добавил: демередж (эффективный остаток `floor + (balance − floor) × (1 − rate)^n`), сжигаемую комиссию (`max(fee_min, rate × amount)`), окно переводимости свежих выпусков, порог P отложенных переводов (задержка D = 48 ч) и мораторий на вывод.

**Главная метрика — безубыточная цена единицы:** внешняя цена, при которой ферма выходит в ноль за выбранный срок. Она не требует угадывать курс.

## Ключевые результаты

База (K=3, слоты 3/5/10, посев 100, ферма 20 устр./мес., device_cost $120 — канон, 8 прогонов × 60 мес.): к 12-му месяцу ферма достигает 11,5% сети ($0,294 за единицу), к 24-му — 34,3% ($0,0394), пик — 38,6% на 28-м месяце; безубыточная цена опускается до $0,01 лишь на 39-м месяце, к 60-му — 12,0% ($0,0053). При нулевом проникновении к честным поручителям ферма не стартует вовсе; посевной круг ≥ 300 сжимает её долю к 60-му месяцу до ~5%.

Допущение «одно устройство = один кошелёк» протоколом не проверяется — несколько кошельков на устройстве снижают эффективную стоимость кошелька (device_cost / wallets_per_device). Вывод устойчивости проверяется сеткой чувствительности device_cost {120, 200} × wallets_per_device {1, 2, 4} (`python farm_model.py --a9`; канон $120 — консервативно для вывода платформы: даже при дешёвом устройстве ферма не окупается; $200 — только в сетке).

Этап 1.2: демередж без окна переводимости не влияет на ферму (она не хранит, а сливает по факту выпуска); **окно переводимости — единственный рычаг**: 3 мес. сдвигают безубыточность фермы на 44-й месяц, 12 мес. — на 58-й. Комиссия даёт +1–2% дрена; порог P и мораторий на этой шкале — ноль. Пересечение $0,01 за 60 мес. не уходит ни в одной комбинации, терпимой для честных. Рекомендованные параметры сети: демередж 1%/мес. + floor 3000; комиссия 1% (границы 0,5–2%, `fee_min` 1); окно переводимости 3 мес.; мораторий 14 дней; P = 3000, P_max = 30000.

## Что не моделируется

Подписи, сеть и финализация, PoW как вычисление (заменён стоимостью), сговор нескольких ферм, адаптивное поведение фермы, обман честных людей, меняющийся спрос. Честные люди могут повторно просить одних и тех же знакомых (небольшая оптимистичность). Допущения, не подтверждённые данными: оборот честных кошельков 0,2–1,0 выпуска и целевой рост предложения для адаптивной комиссии — калибровка на первом пилоте.

## Как читать результаты

Канон базы 1.1 (numpy-путь, 8 прогонов) — `Mistral/results/base/`; исторический каталог этапа 1.1 — `Mistral GLM 5.3/` (архив, прогоны до фиксации единого пути ГПЧ). Свипы этапов 1.2/3/4 и тема A9 — `Mistral/results/` и `Mistral/REPORT.md`; воспроизводимость — манифесты SHA-256 (`Mistral/results/MANIFEST-S01-S08.sha256`, `a9_manifest.sha256`, побайтная сверка seed — `./Mistral/reproduce_a9.sh`). Числа — ориентир для сравнения сценариев, а не прогноз: параметры честного роста и поведения фермы взяты как правдоподобные допущения и требуют калибровки на реальных сообществах.
