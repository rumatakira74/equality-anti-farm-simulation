## S-01 — каноническая стоимость устройства и сетка чувствительности

Решение владельца: **канон device_cost = $120** (консервативно для вывода
платформы: даже при дешёвом устройстве ферма не окупается — вывод robust);
**$200 — только в сетке чувствительности**. Допущение «одно устройство =
один кошелёк» протоколом не проверяется: параметр `wallets_per_device`
снижает эффективную стоимость кошелька (device_cost / wallets_per_device);
сетка значений {1, 2, 4}.

- `Mistral/farm_model.py`: `DEVICE_COST_PUBLIC` → `DEVICE_COST_CANONICAL`
  (120.0) + `DEVICE_COST_SENSITIVITY` (200.0); механизм
