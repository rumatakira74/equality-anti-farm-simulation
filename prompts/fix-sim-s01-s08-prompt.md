## Контекст

Аудит Claude (Sonnet) модели фарминга (ветка audit-sonnet, отчёт audit/results/AUDIT-anti-farm-simulation.md) зафиксировал 13 находок. Мандат закрывает две: S-01 и S-08. **S-01 (HIGH) — стоимость кошелька фермы.** В коде device_cost = 120.0 (Mistral/farm_model.py; копия в Claude Sonnet 3.6/farm_model.py), в документах заявлено «$200 за устройство» (KNOWLEDGE.md, README каталогов моделей). От значения зависят ключевые числа: месяц пересечения порога $0,01 (39-й при $120, 53-й при $200), безубыточная цена на 60-м месяце. Допущение «один кошелёк = одно устройство» протоколом не обеспечено (второй кошелёк на том же телефоне с другим ключом доказать нельзя): при нескольких кошельках на устройстве экономика фермы в текущей модели занижена в разы.

Решение владельца: каноническое значение device_cost = $120 (консервативно для вывода платформы: даже при дешёвом устройстве ферма не окупается — вывод robust). Значение $200 — только в сетке чувствительности.

**S-08 (MEDIUM) — воспроизводимость.** Две линии генерации случайных чисел: numpy (np.random.default_rng(seed)) и fallback без numpy (random.Random(seed*7919+1)). Опубликованные числа базы 1.1 воспроизводятся точно только без numpy; CSV блока 4 совпадают с numpy-путём (21 из 21). Тест падает без numpy, зависимости не зафиксированы, артефакты получены в разных окружениях.

Решение: единственный путь генерации — numpy (жёсткая зависимость, fallback удалить); все канонические прогоны регенерировать одним окружением с манифестом.
